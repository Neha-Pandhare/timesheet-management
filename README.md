# Timesheet Management System

## Overview
This is a Spring Boot based Timesheet Management System that allows users to log daily work hours for different projects.

## Features
- Create Users
- Create Projects
- Log daily work hours
- View timesheets

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- H2 Database
- Maven

## Architecture

This application follows a 3-tier architecture:

Client (Postman / Browser)
        ↓
Controller Layer
        ↓
Service Layer
        ↓
Repository Layer
        ↓
Database (H2)
